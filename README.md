# QGIS Noise Modelling HRISK Setup

This repository provides a set of scripts and instructions for setting up QGIS with the NoiseModelling and H-RISK plugins on Rocky Linux 9.4. These tools are essential for environmental noise modelling and health risk assessment related to noise exposure.

## Features

- Predict environmental noise levels using NoiseModelling.
- Estimate health risks associated with noise exposure via the H-RISK plugin.
- Seamless integration within QGIS for spatial analysis and visualization.

## Installation

1. Ensure QGIS is installed on your system.
2. Clone this repository:
   ```bash
   git clone https://github.com/orbiwise-sa/qgis-noise-modelling-hrisk-setup.git
   ```

3. Follow the setup instructions provided in the repository to configure the plugins and dependencies.

## Usage

After installation:

1. Open QGIS.
2. Load the necessary spatial data (e.g., buildings, roads, ground types).
3. Utilize the integrated plugins to perform noise modelling and health risk assessments.
